pp Scripts Reference

JavaScript API for Pre-request and Test scripts

Pre-request Script

Runs before the HTTP request. Use it to set variables, modify the URL, or add query parameters.

available pp.variables · pp.request (write) · console · pp.sleep

Test Script

Runs after the response. Use it to assert status codes, validate the body, or inspect headers.

available pp.variables · pp.request (read) · pp.response · pp.test · console · pp.sleep

pp.variables

Pre-request Test

A key-value store shared between Pre-request and Test scripts. Values persist across both scripts within the same request.

get(key) Returns the value for key, or undefined if not set
set(key, value) Stores a value under key
unset(key) Removes key and its value
// Pre-request pp.variables.set("token", "Bearer eyJhbGciOi..."); pp.variables.set("userId", "42"); // Test const token = pp.variables.get("token"); // "Bearer eyJhbGciOi..." const uid = pp.variables.get("userId"); // "42" console.log(token); pp.variables.unset("userId");

pp.request

Pre-request (write) Test (read)

Read and modify the outgoing HTTP request. In Test scripts the request has already been sent, so methods like setUrl have no effect there.

getUrl() Returns the full URL string
setUrl(url) Replaces the entire URL
addQueryParam(key, value) Appends a query parameter
getQueryParam(key) Returns the value of a query param, or undefined
hasQueryParam(key) Returns true if the param exists
removeQueryParam(key) Removes the query parameter
// Read query params set in the URL bar const page = pp.request.getQueryParam("page"); // "1" const sort = pp.request.getQueryParam("sort"); // "desc" // Pre-request: add dynamic params pp.request.addQueryParam("timestamp", Date.now().toString()); console.log(pp.request.getUrl()); // https://api.example.com/users?page=1&sort=desc×tamp=1714392000000

pp.response

Test only

Inspect the HTTP response. Available only in Test scripts — in Pre-request scripts these fields are empty/zero.

status HTTP status code, e.g. 200
body Response body as a raw string
headers Response headers object, e.g. pp.response.headers["content-type"]
time Response time in milliseconds
json() Returns the body as a JSON string if valid, or null. Use JSON.parse(pp.response.json()) to get an object.
// Test script const data = JSON.parse(pp.response.json()); console.log("Status:", pp.response.status); console.log("Took:", pp.response.time, "ms"); console.log("Content-Type:", pp.response.headers["content-type"]); pp.expect(pp.response.status).toEqual(200); pp.expect(data.users.length).toBeGreaterThan(0);

pp.test & pp.expect

Test only

Define test cases that appear in the Test Results tab. Each pp.test block reports pass/fail with its duration.

pp.test(name, fn) Register a named test case. If fn throws, the test fails.
pp.expect(actual) Returns an assertion object with chainable methods (see below)

Assertion methods on pp.expect(actual):

.toEqual(expected) String equality (deep-equal not supported)
.toBe(expected) Alias for .toEqual
.toContain(substring) Checks whether the string contains substring
.toBeTruthy() Passes for non-empty, non-zero, non-null strings
.toBeFalsy() Passes for empty, "0", "null", "undefined"
.toBeGreaterThan(n) Numeric greater-than comparison
.toBeLessThan(n) Numeric less-than comparison
// Test script pp.test("Status is 200", () => { pp.expect(pp.response.status).toEqual(200); }); pp.test("Response is JSON", () => { pp.expect(pp.response.headers["content-type"]).toContain("json"); }); pp.test("Body has users array", () => { const data = JSON.parse(pp.response.json()); pp.expect(data.users.length).toBeGreaterThan(0); });

pp.sleep & console

Pre-request Test

Utilities available in both script types.

pp.sleep(ms) Pauses execution for ms milliseconds (capped at 5000)
console.log(...) Prints to the Console tab (default color)
console.info(...) Prints to the Console tab (green)
console.warn(...) Prints to the Console tab (yellow)
console.error(...) Prints to the Console tab (red)
console.log("Request URL:", pp.request.getUrl()); console.info("All good"); console.warn("Deprecated header used"); console.error("Missing required param"); // Wait 1 second between retries pp.sleep(1000);
